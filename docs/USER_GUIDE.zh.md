# DSH Desktop 用户指南（中文）

DSH Desktop 是 **DeepSeek Harness** 的桌面版 —— 一个开箱即用的本地 AI 助手工作台。
不需要任何技术背景：不用装 Node.js、不用开命令行、不用理解「服务」和「端口」。

---

## 一、安装

1. 双击安装包 **DSH-Desktop-Setup-xxx.exe**。
2. 点击「安装」，等待完成（约 1-2 分钟）。
3. 安装完成后应用会自动启动；桌面和开始菜单都会出现 **DSH Desktop** 快捷方式。

> 若 Windows 提示「Windows 已保护你的电脑」：点击「更多信息」→「仍要运行」。
> 这是因为软件尚未做数字签名（不影响使用）。

## 二、第一次使用

1. 应用启动后，会看到一个加载界面：「正在启动服务…」。首次启动稍慢（约 5-15 秒），之后会快很多。
2. 服务就绪后自动进入 **Harness 工作台**。
3. **配置模型**：首次使用需要在工作台右上角「设置」里填写模型 API Key（例如 DeepSeek 的 API Key，在 https://platform.deepseek.com 申请）。
4. 配置完成后即可开始对话、让 AI 帮你干活。

## 三、日常使用

| 想做什么 | 怎么做 |
|---|---|
| 打开/找回主界面 | 双击系统托盘图标，或再次启动应用 |
| 在浏览器里打开 | 托盘菜单 →「在浏览器中打开」 |
| 修改服务端口 | 设置 → 常规 → 服务端口 → 重启服务 |
| 开机自启 | 设置 → 常规 → 开机自动启动 |
| 关闭窗口后继续运行 | 设置 → 常规 → 关闭窗口时最小化到托盘（默认开启） |
| 安装 Python（可选） | 设置 → 运行环境 → Python → 一键安装 |
| 安装 dsh 命令行（可选） | 设置 → 运行环境 → dsh 命令行工具 → 一键安装 |
| 查看日志 | 启动页/托盘 → 查看日志 |

### 手机访问电脑（局域网）

让手机在同一 Wi-Fi 下访问你的电脑、随时对话：

1. **开启**：设置 → 常规 → **局域网访问（手机扫码）** → 打开 → 重启服务
2. **扫码**：在工作台左侧边栏底部点 **「手机访问」**，弹出二维码
3. 手机扫码 → 自动打开 Harness 页面 → 即可在手机上使用你的电脑

> ⚠️ 安全提示：开启后同一局域网内的设备都能访问（无登录鉴权）。
> 只在家/公司等可信网络开启，公共 Wi-Fi 下请关闭；不使用时建议关闭并重启服务。

### Telegram 接入（随时随地对话控制电脑）

在 **Telegram** 里与你的电脑对话、让 AI 操作电脑（无需同一 Wi-Fi，手机/电脑都能用）：

1. **创建机器人**：在 Telegram 中打开 **@BotFather** → 发送 `/newbot` → 按提示给机器人起名，会得到一串 **Token**
2. **连接**：工作台左侧边栏底部 → **「Telegram 接入」** → 粘贴 Token → **保存并连接**
3. **扫码**：连接成功后显示二维码（内容为 `https://t.me/<机器人用户名>`）——手机扫码直达对话
4. **开始对话**：在 Telegram 里给机器人发消息即可；AI 的回复和操作电脑的结果都会发回 Telegram

> 说明：Telegram 桥接复用 Harness 的同一个会话（和浏览器工作台同步）；需要电脑保持运行、
> 且网络能访问 Telegram（国内网络环境下可能需要代理）。

### 托盘图标说明

- 单击：显示主界面
- 右键菜单：在浏览器打开 / 设置 / 重启服务 / 退出

### 进阶：插件 npx 独立安装（开发者 / 命令行用户）

桌面版已**内置**以上两个插件（局域网二维码、Telegram 桥接），普通用户无需任何操作。
两个插件同时也以**独立 npm 包**分发，可在任意 DeepSeek Harness（`dsh web`）环境里用 npx 一键安装：

```bash
npx dsh-plugin-lan-access                  # 安装「局域网二维码」插件
npx dsh-plugin-telegram-bridge             # 安装「Telegram 桥接」插件
```

- 安装器会把插件复制到 `~/.dsh/profiles/web/node_modules/@dsh-desktop/` 并生成注入 patch，
  完成后按提示以 `dsh web --patch <插件>.patch.yml` 重启即可生效（可用 `--dsh-home` 指定 DSH 数据目录）。
- 插件源码与使用说明分别在独立仓库：
  - <https://github.com/yansenlei/dsh-plugin-lan-access>
  - <https://github.com/yansenlei/dsh-plugin-telegram-bridge>
- 桌面版内置版本与 npm 独立版本同源同步；桌面版用户请继续使用「设置」里的开关，无需 npx。

## 四、常见问题（FAQ）

**Q: 提示「端口被占用」或一直停留在启动页？**
A: 应用默认使用 3080 端口，被占用时**自动顺延**。若仍无法启动，打开 设置 → 服务管理 → 重启服务；或修改端口后重启。

**Q: 卸载会删除我的聊天记录吗？**
A: 不会。卸载只删除程序本体；会话数据保存在「数据目录」（设置 → 数据与日志 → 打开），可手动备份。

**Q: 需要安装 Node.js 吗？**
A: 不需要。应用已内置运行环境。

**Q: Python 有什么用？一定要装吗？**
A: 可选。AI 代理需要执行 Python 脚本时才用得到；不装也能正常使用绝大部分功能。

**Q: dsh 命令行工具是什么？**
A: 可选的命令行版本（终端里输入 `dsh` 使用）。普通用户用不到，无需安装。

**Q: 服务崩溃了怎么办？**
A: 应用会自动重启服务（最多 3 次）。若持续失败，打开 设置 → 服务管理 → 重启服务，并查看运行日志定位原因。

## 五、数据与隐私

- 所有数据（会话、配置）都保存在本机「数据目录」，**不会上传**。
- 只有你配置的模型 API Key 会通过网络发送给对应的大模型服务商（用于对话）。
- 应用会在本地写入运行日志（用于排查问题），不会上报。

## 六、更新

当前版本暂未接入自动更新；新版本请重新下载安装包覆盖安装（数据不丢失）。
