# 推广文案稿（docs/promotion）

本目录存放各平台的发布文案模板，发布前请按平台要求改写（不要一稿多发，知乎/掘金有查重）。

## 使用说明

1. **发布顺序建议**：V2EX / LINUX DO（即时反馈）→ 掘金 → 知乎 → 微信公众号/少数派 → 视频平台（B站/小红书/抖音）。海外：HN Show HN → Product Hunt → Reddit。
2. **时机**：晚上 20:00-22:00 或周末上午；发布当天集中回复评论（前 2 小时最关键）。
3. **配图**：下载页截图（`site/deepseek-harness.png`）+ 一个 30 秒演示 GIF（建议用 Kap/ScreenToGif 录：双击安装 → 启动 → 聊上 AI）。
4. **统一行动号召**：文末放下载页链接 + GitHub 链接 + "好用请点个 Star ⭐"。
5. **版本号**：文中 v0.2.7 如已过时请替换为当前版本。
6. **诚实声明**：这是社区非官方项目，文案中务必保留"与 DeepSeek 官方无隶属关系"的说明，避免误解与投诉。

## 文案清单

| 文件 | 平台 | 调性 |
|---|---|---|
| `v2ex.md` | V2EX › 分享创造 | 真诚技术分享，贴代码贴架构 |
| `linuxdo.md` | LINUX DO › 搞七捻三 | 轻松、社区感强，允许自嘲 |
| `juejin.md` | 掘金 › 前端/Electron | 技术干货向，讲架构 |
| `zhihu.md` | 知乎（文章+回答） | 面向非技术用户，教程向长文 |
| `hn-show-hn.md` | Hacker News Show HN | 英文，简洁，讲 what/why/how |
| `producthunt.md` | Product Hunt | 英文，tagline + 首发评论 + 更新模板 |

## 发布后跟踪

- 知乎文章发布后，去回答相关问题（标题即关键词），文末挂文章链接；
- V2EX/LINUX DO 帖子被顶后不要刷，真诚回复即可；
- HN/PH 发布后把链接同步到 Reddit r/selfhosted、r/LocalLLaMA、r/DeepSeek；
- 发布当天在 Release 页面加一段"本周社区动态"（引用热帖链接）。
