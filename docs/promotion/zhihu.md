**回答可投的问题（标题即关键词）**：

**正文**：

## 一句话说明

DeepSeek Harness Desktop 是一个**社区开源**的桌面客户端（非官方出品），把 DeepSeek Harness 完整打包进安装包：**双击 → 安装 → 自动启动**，不用装 Node.js、不用开终端、不用理解"服务""端口"。

> 下载：https://yansenlei.github.io/dsh-desktop/（自动识别你的系统）

## 适合谁

- 想用 AI 干活的普通人：写材料、查资料、整理表格、让 AI 操作电脑
- 想给家人朋友装一个"开箱即用"的 AI 助手的人

## 装好之后能干嘛

1. **直接对话干活**：接入你的 DeepSeek API Key（在平台官网申请）就能用；
2. **手机扫码远程用**：电脑和手机连同一个 Wi-Fi，扫一下侧边栏二维码，躺沙发上继续指挥电脑（默认关闭，设置里一键开）；
3. **出门了也能用**：绑定你自己的 Telegram 机器人，人不在电脑前，发消息照样让 AI 干活；
4. **自动更新**：设置 → 检查更新 → 一键下载安装，以后不用重装。

## 常见疑问（避坑）

**Q1：macOS 提示"无法验证开发者"？**
点「打开」就行（或右键 → 打开），只需一次。这是社区项目没有购买苹果开发者证书的缘故，不是病毒。

**Q2：Windows 提示"已保护你的电脑"？**
点「更多信息」→「仍要运行」。开源包未做商业签名，属正常现象。

**Q3：会偷我数据吗？**
完全本地运行：会话、配置都存在你自己的电脑上（应用数据目录），卸载也不删数据。代码全部开源，可自行审查。

**Q4：和官方什么关系？**
这个桌面版是社区项目（MIT 开源），基于官方开源的 deepseek-harness 构建，与 DeepSeek 官方无隶属关系。
