一键安装

NSIS 安装包双击即装：桌面/开始菜单快捷方式、卸载器齐全，装完自动启动，30 秒进入工作台。

免装 Node.js

应用自带 Electron（内置 Node 24 运行时），DSH 服务在应用内以子进程运行 —— 电脑上什么都不用装。

数据自包含

会话、配置、存储都放在应用数据目录，卸载不丢数据；端口冲突自动顺延，服务崩溃自动重启。

自动更新

「设置 → 检查更新」一键下载并安装新版（以 GitHub Releases 为更新源），Windows / macOS 同步支持。

安装说明

常见问题速查 —— 点击展开。

v0.2.4 起安装包为 ad-hoc 签名：首次打开提示「无法验证开发者」时，直接点击「打开」即可（或右键应用 → 打开），只需一次，无需终端。
若旧版本（v0.2.3 及更早）提示「已损坏，无法打开」，请改装 v0.2.4 及以上版本；或临时在终端执行： codesign --force --sign - "/Applications/DeepSeek Harness Desktop.app"
安装包未做商业代码签名，SmartScreen 会提示「未知发布者」：点击「更多信息」→「仍要运行」即可正常安装。来源请认准本页与 GitHub 仓库 yansenlei/dsh-desktop 的 Release。
不会。会话、配置、存储都保存在应用数据目录（Windows：%APPDATA%\DeepSeek Harness Desktop；macOS：~/Library/Application Support/DeepSeek Harness Desktop），卸载不删除，重装即恢复。
不需要处理。服务默认使用 3080 端口，被占用时自动顺延到下一个可用端口并照常启动。
应用内「设置 → 检查更新」：检测到新版本后一键「下载并安装」，Windows（静默安装）与 macOS（自动替换 .app 并重启）均无需手动操作。
